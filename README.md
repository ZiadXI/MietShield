# MietShield 🛡️

> *Miet (rent) + Shield (protection)* — AI-powered tenant rights assistant for Germany.

Helps tenants — especially international students — understand their rights under German rental law (Mietrecht) using a multi-agent AI system built with **LangGraph**.

## What It Does

- **Ask questions** about your rights as a tenant in Germany
- **Upload your lease** and get a clause-by-clause breakdown with risk flags

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | HTML / CSS / JS |
| Backend | Python, FastAPI |
| AI | LangGraph, OpenRouter |
| Knowledge | FAISS (in-memory RAG) |
